# Nunito Sans

Source: [Google Fonts / Nunito Sans](https://github.com/google/fonts/tree/main/ofl/nunitosans).
License: SIL Open Font License 1.1; the complete license is included in OFL.txt.

The local WOFF2 retains Latin, Latin Extended, combining accents, Vietnamese and common punctuation/currency glyphs. Weight remains variable from 500 to 800; optical size is pinned to 12, width to 100 and YTLC to 500. The file is 45,656 bytes. All 134 distinct Vietnamese sample characters passed cmap verification.

Loaded once in the root layout through next/font/local. No external font request is needed at runtime or build time.
